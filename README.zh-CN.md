### 🔬 [Anettrace](https://github.com/ron159/Anettrace)

**跟着数据包走，把网络问题看清楚。**

基于 [nettrace](https://github.com/OpenCloudOS/nettrace) 演进的 eBPF 网络诊断工具，面向 Linux 和已 root 的 Android 设备。追踪报文在内核中的路径，定位丢包与延迟，把线程流量和系统调度放进同一条 Perfetto 时间线。

`Linux · 已 root 的 Android` · `C · eBPF · Perfetto`

[下载](https://github.com/ron159/Anettrace/releases) · [使用手册](https://github.com/ron159/Anettrace/wiki) · ![Anettrace 最近更新](https://img.shields.io/github/last-commit/ron159/Anettrace?style=flat&label=updated)

### 🦦 [OtterDive](https://github.com/ron159/OtterDive)

<img align="right" src="https://raw.githubusercontent.com/ron159/OtterDive/main/crates/otterdive-app/icons/icon-source.png" width="72" height="72" alt="OtterDive 水獭应用图标">

**潜入海量文本，捞出真正重要的内容。**

基于 [Notra](https://github.com/syscryer/Notra) 演进的本地优先桌面工具，把文本、日志、Markdown 和代码放进同一个工作区。用 Monaco 编辑，跨文件搜索，用 Regex 和 Analyse 深挖结果，写 Markdown 时随手切换编辑与预览。

`Windows · macOS · Linux` · `Rust · Tauri · TypeScript`

[下载](https://github.com/ron159/OtterDive/releases) · [项目介绍](https://github.com/ron159/OtterDive#readme) · ![OtterDive 最近更新](https://img.shields.io/github/last-commit/ron159/OtterDive?style=flat&label=updated)

### 🐹 [iGestures](https://github.com/ron159/iGestures)

<img align="right" src="https://raw.githubusercontent.com/ron159/iGestures/main/iGestures/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-512.png" width="72" height="72" alt="iGestures 仓鼠应用图标">

**按住、画一下、松开——剩下的交给 Mac。**

原生鼠标手势工具，把熟悉的轨迹变成顺手的动作。为单个应用、应用分组或整个系统设置手势，分享自己的配置，让常用操作跟着手走；手势识别在本机完成。

`macOS · Apple Silicon` · `Swift · SwiftUI · AppKit`

[下载](https://github.com/ron159/iGestures/releases) · [项目介绍](https://github.com/ron159/iGestures#readme) · ![iGestures 最近更新](https://img.shields.io/github/last-commit/ron159/iGestures?style=flat&label=updated)

### 🐾 [Meerkat Reader](https://github.com/ron159/MeerkatReader)

<img align="right" src="https://raw.githubusercontent.com/ron159/CraftEcho-Icons/main/app/src/main/res/drawable-nodpi/icon_meerkat_reader.png" width="72" height="72" alt="Meerkat Reader 狐獴形象">

**信息很多，阅读可以安静一点。**

从 [Capy Reader](https://github.com/jocmp/capyreader) 演进而来的 Android RSS 阅读器。连接 Feedbin、FreshRSS、Miniflux、Google Reader API 兼容服务或本地订阅，支持全文阅读、语音朗读、Wallabag 稍后读和 WebDAV 备份，并可自定义排版与手势。

`Android 11+` · `Kotlin · Jetpack Compose`

[项目介绍](https://github.com/ron159/MeerkatReader#readme) · ![Meerkat Reader 最近更新](https://img.shields.io/github/last-commit/ron159/MeerkatReader?style=flat&label=updated)

### 🎨 [CraftEcho Icons](https://github.com/ron159/CraftEcho-Icons)

**让屏幕上的小物件，重新有一点质感和温度。**

我维护的 [CraftEcho Icons](https://github.com/gaodeng/CraftEcho-Icons) 分支，延续并适配 Smartisan OS 经典拟物风格的非官方 Android 图标包。继续补充图标、修整应用映射，让这些精致的小物件在新设备上也能找到位置。

`Android 启动器` · `Kotlin · Blueprint`

[项目介绍](https://github.com/ron159/CraftEcho-Icons#readme) · ![CraftEcho Icons 最近更新](https://img.shields.io/github/last-commit/ron159/CraftEcho-Icons?style=flat&label=updated)
